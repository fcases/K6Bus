===============================================================================
4. CRITERIOS DE ACEPTACION DEL MINIPASO
===============================================================================

- El codigo generado compila con Zig 0.15.1.
- Se insertan todos los mensajes repeated.
- Se conserva el orden.
- No se copian superficialmente campos owned.
- No hay leaks ni double-free.
- Si falla un append o un parseo posterior, se liberan los elementos previos.
- Tras transferir el contenido al campo final, la lista temporal no vuelve a
  liberar los elementos transferidos.
- El diff generado es pequeno y comprensible.

===============================================================================
5. REGLAS QUE NO SE DEBEN ROMPER
===============================================================================

- initDefault()/deinit() es la pareja estandar.
- Los mensajes owned no se copian superficialmente.
- Antes de sobrescribir memoria owned se libera el valor anterior.
- get de string/bytes es borrowed.
- get de message devuelve copia owned.
- oneof libera la rama previa antes de activar otra.
- Repeated preserva orden.
- ZON/JSON no crean defaults owned implicitos tras parsear.
- La configuracion AppConfig es temporal durante init.
